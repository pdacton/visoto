About Plazi

Plazi is a not-for-profit organisation that liberates taxonomic knowledge from the scientific literature. It converts descriptions of species — so-called treatments — from published articles into machine-readable, openly accessible data, and publishes them as linked data.

Every organism described in the literature is placed within a hierarchical classification. At its very top sit a handful of kingdoms that group all living things. Each kingdom below is represented by a TaxonName resource that you can explore in Visoto to drill down through the tree of life.

SELECT (COUNT(?taxonName) AS ?count) WHERE { ?taxonName a dwcFP:TaxonName . ?taxonName dwc:kingdom "Animalia" . } SELECT (COUNT(?taxonName) AS ?count) WHERE { ?taxonName a dwcFP:TaxonName . ?taxonName dwc:kingdom "Plantae" . } SELECT (COUNT(?taxonName) AS ?count) WHERE { ?taxonName a dwcFP:TaxonName . ?taxonName dwc:kingdom "Fungi" . } SELECT (COUNT(?taxonName) AS ?count) WHERE { ?taxonName a dwcFP:TaxonName . ?taxonName dwc:kingdom "Bacteria" . } SELECT (COUNT(?taxonName) AS ?count) WHERE { ?taxonName a dwcFP:TaxonName . ?taxonName dwc:kingdom "Chromista" . } SELECT (COUNT(?taxonName) AS ?count) WHERE { ?taxonName a dwcFP:TaxonName . ?taxonName dwc:kingdom "Protozoa" . }

The dataset

The Plazi classification shown above is backed by the Plazi Taxonomic Treatments dataset, published on LINDAS in the named graph https://lindas.admin.ch/foen/plazi.

Plazi TreatmentBank deals with scientific, published, biosystematic literature — the corpus documenting all of the world's ca. 1.9 million known species across an estimated 500 million published pages. Each treatment is a well-defined part of an article that fixes the usage of a scientific name by an author at a given time; like bibliographic references, treatments can be cited and build on earlier ones. Together they represent the current scientific consensus on biological taxonomy, fully reference the underlying literature, and link to specimens and images archived at Zenodo/CERN. The cited publications are available through the Biodiversity Literature Repository.

Classes in the dataset

The classes below are every class either declared in the graph as an rdfs:Class/owl:Class or used as the object of an rdf:type statement, ordered by the number of instances of each. Where a class is defined in a vocabulary loaded in the store, its description is shown. The biodiversity content is carried by the first rows (material citations, taxon concepts and names, treatments, figures and articles); the single-instance rows describe the dataset itself.

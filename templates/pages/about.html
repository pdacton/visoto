About Visoto

Visoto is a graph exploration and visualization tool for RDF data. It provides an more intuitive interface for browsing, querying, and understanding linked data.

Acknowledgements

This project builds upon the work of many talented teams and open-source communities:

  • fluidOps for the original concept behind the Information Workbench
  • Go for the programming language
  • Gin for the web framework
  • Tabulator for interactive data tables
  • Tabler for the admin dashboard template
  • Bootstrap for the CSS framework
  • Lucide for the icon set
  • Claude Code for AI-assisted development

{{ t "page.environment.aboutThisTheme" "About this theme" }}

{{ tHTML "page.environment.oneOfficeManyClocks" "This theme has a single publisher — the Federal Office for the Environment — and that is what makes it unusual. Everything here comes from one office, but the datasets run on wildly different clocks. The hydrological network reports every ten minutes. Forest fire warnings are reissued when the weather turns. The National Forest Inventory takes roughly a decade to complete one pass. The Red List is revised once a generation." }}

{{ tHTML "page.environment.readTheClockFirst" "That spread is the thing to keep in mind while reading these tables. A number from the hydro graph is a reading and will have changed by the time you refresh; a number from the forest inventory is an estimate with a published margin of error; a number from the Red List is an assessment that stands until the next revision. The data model tells you which is which — the inventory even ships its own standard errors — but only if you look." }}

{{ t "page.environment.forestFireDanger" "Forest fire danger" }}

{{ tHTML "page.environment.fireDangerIntro" "Switzerland is divided into 143 forest fire warning regions, each carrying a danger level from 1 (low) to 5 (very high). What makes this pair of graphs worth reading together is that danger and response are published separately: FOEN assesses the risk, and the cantons decide what to forbid. The table below joins them, so each region shows the hazard alongside the fire ban actually in force there — from a warning to take care, up to an absolute ban on fires in the open." }}

# ?region, ?canton, ?dangerLevel and ?measure all stay IRIs on purpose: the backend # resolves each to a label in the visitor's language and links it to its resource page. # # The join is across TWO named graphs — the warning (FOEN's hazard assessment) and the # cantonal prevention measure (the legal response) are separate datasets that share the # region IRI. It is an OPTIONAL because not every region has a measure in force; the # join stays 1:1 (143 rows in, 143 out), so no aggregation is needed to keep it flat. # # ?issued is the warning's own timestamp rather than a query time — these rows are # reissued as the weather changes, so a stale-looking date is information, not a bug. {{ t "page.environment.riversAndLakes" "Rivers and lakes, this minute" }}

{{ tHTML "page.environment.hydroIntro" "The hydrological network is the most immediate dataset on this platform. Around 230 stations report water level, discharge and — at some of them — water temperature, refreshed continuously; the timestamp on each row is when the instrument actually read, not when the file was published. Each station is tied to the body of water it sits on and carries geographic coordinates, so the same reading answers both how warm is the Rhine and where exactly." }}

{{ tHTML "page.environment.hydroWhatIsMissing" "Note which columns are sparse. Every station reports a level, most report discharge, but only about a third measure temperature — and lake stations naturally report no discharge at all. Those gaps are in the data rather than in the query: the measures are OPTIONAL because a station simply does not carry the instruments it does not have." }}

# ?station and ?water stay IRIs so the backend resolves and links them; the station page # carries the coordinates and the water body page groups every station on that river. # # All three measures are OPTIONAL because station equipment differs — a lake gauge has # no discharge, and only about a third of stations carry a thermometer. Making any of # them mandatory would silently drop most of the network from the table. # # Sorted by temperature descending so the warmest water in the country is the first row; # unmeasured stations sort to the end rather than disappearing. SELECT ?station ?water ?waterTemperature ?discharge ?waterLevel ?measured WHERE { GRAPH <https://lindas.admin.ch/foen/hydro> { ?obs a cube:Observation ; <https://environment.ld.admin.ch/foen/hydro/dimension/station> ?station ; <https://environment.ld.admin.ch/foen/hydro/dimension/measurementTime> ?measured . OPTIONAL { ?obs <https://environment.ld.admin.ch/foen/hydro/dimension/waterTemperature> ?waterTemperature } OPTIONAL { ?obs <https://environment.ld.admin.ch/foen/hydro/dimension/discharge> ?discharge } OPTIONAL { ?obs <https://environment.ld.admin.ch/foen/hydro/dimension/waterLevel> ?waterLevel } ?station schema:containedInPlace ?water . } } ORDER BY DESC(xsd:decimal(?waterTemperature))

{{ t "page.environment.theStateOfTheForest" "The state of the forest" }}

{{ tHTML "page.environment.nfiIntro" "The National Forest Inventory is the most carefully modelled dataset in this theme, and the one that rewards reading the model before the numbers. Field crews visit a grid of sample plots across the country; a full pass takes years. Five inventories have been completed since the early 1980s, and — importantly — the data also treats the intervals between them (NFI1–NFI2, NFI2–NFI3, …) as inventory periods in their own right, so change over time is a first-class value rather than something you compute by subtraction." }}

{{ tHTML "page.environment.nfiStandardError" "Because every figure is an estimate from a sample rather than a census, each measure ships with its own standard error: alongside topic 21 (growing stock) sits SE21, the error on that estimate as a percentage. This is genuinely unusual for open government data, and it changes how the table should be read — a cantonal figure with ±15% attached is not comparable to one with ±6% in the way the raw numbers suggest. Small cantons have fewer sample plots, so their estimates are correspondingly less certain." }}

# Growing stock per hectare, by canton, from the most recent completed inventory (NFI5). # ?canton stays an IRI so the backend resolves and links it to the standard canton page. # # FOUR dimensions must be pinned or this cube fans out badly — each is a real choice: # 1. inventory = 550 (NFI5). Omitting it returns all five inventories AND the # four change periods between them, stacked. # 2. classificationUnit = Total. This cube breaks results down by tree diameter class; # "Total" is the aggregate. (ClassificationUnit/1029/0 looks like # a total but is the 12-15 cm class — an easy and silent mistake.) # 3. evaluationType = 1 ("State"), i.e. a stock figure rather than a rate of change. # 4. unitOfEvaluation = 434, "accessible forest without shrub forest" as assessed for # THIS inventory. The alternative (2382) is the same population # restricted to what is comparable across NFI1-NFI5 — correct for # time series, wrong here, and it silently doubles the row count. # # ?standardErrorPercent is the published error on the estimate to its left, not a # separate measurement. Read the two columns together. SELECT ?canton ?stockPerHectare ?standardErrorPercent ?observation WHERE { GRAPH <https://lindas.admin.ch/foen/national-forest-inventory> { <https://environment.ld.admin.ch/foen/nfi/nfi_C-1029/cube/2024-1> cube:observationSet/cube:observation ?observation . ?observation <https://environment.ld.admin.ch/foen/nfi/inventory> <https://environment.ld.admin.ch/foen/nfi/Inventory/550> ; <https://environment.ld.admin.ch/foen/nfi/unitOfReference> ?canton ; <https://environment.ld.admin.ch/foen/nfi/classificationUnit> <https://environment.ld.admin.ch/foen/nfi/ClassificationUnit/Total> ; <https://environment.ld.admin.ch/foen/nfi/evaluationType> <https://environment.ld.admin.ch/foen/nfi/EvaluationType/1> ; <https://environment.ld.admin.ch/foen/nfi/unitOfEvaluation> <https://environment.ld.admin.ch/foen/nfi/UnitOfEvaluation/434> ; <https://environment.ld.admin.ch/foen/nfi/Topic/21r> ?stockPerHectare ; <https://environment.ld.admin.ch/foen/nfi/Topic/SE21r> ?standardErrorPercent . FILTER (CONTAINS(STR(?canton), "/canton/")) } } ORDER BY DESC(xsd:decimal(?stockPerHectare))

{{ tHTML "page.environment.nfiTopicCaveat" "The inventory publishes each measure as its own predicate rather than as a value of a shared dimension — Topic/21 is growing stock, Topic/13 is fellings and mortality, and so on for several hundred topics, each with an r variant expressing it per hectare. So changing what this table reports means changing a predicate, not a filter." }}

{{ tHTML "page.environment.nfiCantonCaveat" "Twenty-four rows, not twenty-six: Basel-Stadt and Basel-Landschaft are not reported separately in this cube — they appear only as a combined region — and the inventory also publishes the same topics for Switzerland as a whole, for economic regions and for protection-forest regions. The unit of reference is a dimension in its own right, so a canton is one of several ways to slice the forest rather than the only one." }}

{{ t "page.environment.whatHasBeenLost" "What has been lost" }}

{{ tHTML "page.environment.redListIntro" "The Red List assesses Swiss species against the IUCN conservation categories — from least concern through vulnerable, endangered and critically endangered, to regionally extinct. Each category is a proper resource here, not a code in a string: it carries its four-language name, an owl:sameAs link to Wikidata, and even the official colour used to render it on FOEN's own charts." }}

{{ tHTML "page.environment.redListStructure" "Species are grouped by a FOEN classification that nests via skos:broader — all organisms contains animals, which contains insects, which contains butterflies — so the same cube answers both the national headline and the question of which group is faring worst. Pick one level when summing, or the totals will count the same species several times over. The part column is the share of that group's assessed species falling in the category, which is what makes small and large groups comparable." }}

# ?group and ?status stay IRIs so the backend resolves both to labels and links them — # the status page carries the IUCN definition and the Wikidata link. # # Only the TOP level of the species hierarchy is selected (foen_species_classification # /100000, "all organisms" and its immediate children are nested via skos:broader). # Listing every level would double-count, since a butterfly is also an insect and an # animal; the ?group link leads to the finer breakdown. # # ?share is the cube's own "part" measure — the percentage of that group's assessed # species in this category — so it is comparable across groups of very different size. # # Note there is deliberately NO year filter. This cube's yearissue is the literal # string "no" for the current assessment (it is not a per-year series), so filtering # on a year would empty the table. SELECT ?group ?status ?species ?share ?observation WHERE { GRAPH <https://lindas.admin.ch/foen/cube> { <https://environment.ld.admin.ch/foen/ubd003001/10> cube:observationSet/cube:observation ?observation . ?observation <https://environment.ld.admin.ch/foen/ubd003001/statuscode> ?status ; <https://environment.ld.admin.ch/foen/ubd003001/groupid> ?group ; <https://environment.ld.admin.ch/foen/ubd003001/value> ?species ; <https://environment.ld.admin.ch/foen/ubd003001/part> ?share . } } ORDER BY ?group DESC(xsd:decimal(?species))

{{ tHTML "page.environment.redListDataDeficient" "Watch the data deficient rows. They are not a category of threat but an admission that too little is known to assess the species at all, and for some groups they outnumber every threat category combined — a statement about the survey effort rather than about the organisms." }}

{{ t "page.environment.emissionsAndPollution" "Emissions and pollution" }}

{{ tHTML "page.environment.ghgIntro" "The greenhouse gas inventory is the dataset behind Switzerland's climate reporting, running from 1990 to the most recent completed year. It is broken down by sector and by gas, and both are hierarchical: the national total splits into buildings, transport, industry and other, while the gases split into CO₂, methane, nitrous oxide and the synthetic gases — with an all greenhouse gases member expressing everything in CO₂ equivalents." }}

{{ tHTML "page.environment.ghgLandUse" "One part of the model deserves attention: land use is reported separately and excluded from the headline total, as is international aviation. Forest land in particular is usually a net sink — a negative number — because growing trees absorb more carbon than felling releases. Folding it into the national figure would understate emissions; keeping it out is the convention, and the cube marks it explicitly rather than leaving you to guess." }}

# ?sector stays an IRI so the backend resolves the sector name and links it. # # Three traps in this cube: # 1. The year is typed xsd:gYear, NOT a plain string — "2024" alone matches nothing. # 2. The "all greenhouse gases" member (everything in CO2 equivalents) has the # misleading IRI .../testdimension/test1. It is not test data — it is the total, # and using a single gas instead would silently report only part of the emissions. # 3. ?hierachie (sic, misspelled in the source data) is the depth of the sector in # the hierarchy: "1" is the national total, two-digit codes are its components. # Mixing levels double-counts, so it is selected rather than filtered out — the # column makes the nesting visible instead of hiding it. SELECT ?sector ?level ?megatonnesCO2eq ?year ?observation WHERE { GRAPH <https://lindas.admin.ch/foen/cube> { <https://environment.ld.admin.ch/foen/ubd000502/8> cube:observationSet/cube:observation ?observation . ?observation <https://environment.ld.admin.ch/foen/ubd000502/sektorid> ?sector ; <https://environment.ld.admin.ch/foen/ubd000502/gas> <https://ld.admin.ch/cube/dimension/testdimension/test1> ; <https://environment.ld.admin.ch/foen/ubd000502/jahr> ?year ; <https://environment.ld.admin.ch/foen/ubd000502/hierachie> ?level ; <https://environment.ld.admin.ch/foen/ubd000502/werte> ?megatonnesCO2eq . FILTER (STRLEN(?level) <= 2) } } ORDER BY DESC(?year) ?level DESC(xsd:decimal(?megatonnesCO2eq))

{{ tHTML "page.environment.otherPollutionCubes" "Several smaller cubes round out the pollution picture, and each is worth knowing about even though none is tabulated here. Traffic noise pollution estimates how many people are exposed to road, rail and aircraft noise above the legal thresholds. Heavy metal soil contamination reports measured concentrations at monitoring sites. Bathing water quality holds roughly twelve thousand individual laboratory results — E. coli and enterococci counts per sampling date and location — which is a genuinely fine-grained public health series. And a family of cubes tracks air pollution along the A2 and A13, the two motorways carrying alpine transit traffic, measuring NO₂, particulates and soot at roadside." }}

{{ t "page.environment.speciesLiterature" "Species literature" }}

{{ tHTML "page.environment.plaziIntro" "The largest graph FOEN publishes has nothing to do with monitoring. Plazi is a corpus of taxonomic treatments — the formal descriptions by which species are named and delimited in the scientific literature — mined from published papers and turned into linked data. It answers a different kind of question from everything above: not how much or how warm, but who described this species, where, and under what name. It has its own page here, because its structure has nothing in common with the cubes." }}

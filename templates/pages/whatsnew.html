Some recent changes to visoto

  1. Added links to the menu to make cubes (cube.link) entities accessible
  2. The graph explorer has been improved, however, it only works on the LINDAS next end points (due to limitation of Stardog)
  3. Added a metrics partial, to display counts of various resource types in the knowledge graph
  4. Select a pre-configured SPARQL endpoint from the menu to connect Visoto to other endpoints, particularly useful when comparing different environments like test, dev or prod.
  5. Added a right sidebar with bookmarks and additional context panels
  6. Added SPARQL endpoint response time monitoring
  7. New resource templates for Districts, Countries, and other geographic entities
  8. Async metric cards via HTMX for faster page loads
  9. Expanded resource icons for better visual identification of RDF types
  10. Multi-endpoint SPARQL support with cookie-based endpoint switching
  11. MCP server integration for AI-assisted exploration of the knowledge graph
  12. Shared template components to reduce duplication across resource pages

About this theme

Seventeen LINDAS graphs cover Swiss politics, all published by the Federal Chancellery. That is more graphs than any other theme, and the number is misleading until you see the pattern: they come in two families. The political-rights graphs are cubes of outcomes — every popular vote, initiative and referendum, counted and broken down by canton. The registers are directories of people and bodies — who sits in parliament, who governs, which office reports to which department.

One quirk is worth knowing before you start clicking. Each of the four political-rights subjects is published as a triplet: a main cube with the records themselves, a -stat cube listing the possible statuses, and a key figures cube with aggregates. If a graph name ends in -stat, it is reference data, not the thing itself.

Direct democracy: how a vote happens

Swiss citizens do not only elect a parliament; they vote on the laws themselves, several times a year. Two instruments put a question to the people, and telling them apart is the single most useful thing to understand about this data — they run in opposite directions.

Popular initiative

Citizens propose. Gather 100,000 signatures and you can demand a change to the federal constitution, whether or not parliament wants one. Recorded since 1891 in the popular initiatives cube, which tracks each one through signature collection, withdrawal or ballot.

Referendum

Citizens object. Parliament has passed a law; 50,000 signatures force it to a public vote before it can take effect. The referendum cube covers these along with emergency legislation, which follows its own accelerated rules.

Both routes end at the same place: a popular vote. That cube is the centrepiece of this theme — and the richest political dataset in LINDAS. It records not one row per vote but one row per proposal per canton, which is why a few hundred proposals become nearly twenty thousand observations. Each row carries yes and no counts and percentages, turnout, eligible voters, blank and invalid ballots, and the cantonal vote (Standesstimme) that constitutional amendments must also win.

Petitions

The quietest instrument, and the only one open to everyone — no signature threshold, no citizenship requirement, no minimum age. Anyone may petition the federal authorities, who are obliged to take note but not to act.

Elections: filling the National Council

Every four years Switzerland elects the 200 members of the National Council. LINDAS holds the results as five cube families per election year, and together they describe the whole proportional machinery: who stood, on which list, how many votes each list drew, and how seats were finally allocated — including the distribution within joined lists (listes apparentées), a Swiss speciality where small parties pool votes to clear the threshold together.

SELECT (COUNT(?o) AS ?count) WHERE { GRAPH <https://lindas.admin.ch/fch/national-council-election> { <https://politics.ld.admin.ch/national-council-election/candidates/2023> cube:observationSet/cube:observation ?o . } } SELECT (COUNT(?o) AS ?count) WHERE { GRAPH <https://lindas.admin.ch/fch/national-council-election> { <https://politics.ld.admin.ch/national-council-election/candidates/2019> cube:observationSet/cube:observation ?o . } } SELECT (COUNT(?o) AS ?count) WHERE { GRAPH <https://lindas.admin.ch/fch/national-council-election> { <https://politics.ld.admin.ch/national-council-election/list-results/2023> cube:observationSet/cube:observation ?o . } } SELECT (COUNT(?o) AS ?count) WHERE { GRAPH <https://lindas.admin.ch/fch/national-council-election> { <https://politics.ld.admin.ch/national-council-election/seats-per-list/2023> cube:observationSet/cube:observation ?o . } }

Who governs: people and institutions

Where the cubes above count votes, this family of graphs names people. Curia Vista is the parliamentary register: every member of the Federal Assembly, living and dead, with their party, their parliamentary group, the committees they sat on and the exact dates of each mandate. Because memberships are modelled as dated roles rather than plain links, you can reconstruct the composition of parliament on any given day.

SELECT ?group ?name (COUNT(DISTINCT ?person) AS ?members) WHERE { GRAPH <https://lindas.admin.ch/fch/curia> { ?group a schema:ParliamentaryGroup . ?role schema:memberOf ?group ; schema:member ?person . # Group names exist in de/en/fr/it/rm — one row per group in the visitor's language. OPTIONAL { ?group schema:name ?namePreferred . FILTER (lang(?namePreferred) = visoto:dispLang && STR(?namePreferred) != "") } OPTIONAL { ?group schema:name ?nameEnglish . FILTER (lang(?nameEnglish) = "en" && STR(?nameEnglish) != "") } OPTIONAL { ?group schema:name ?nameGerman . FILTER (lang(?nameGerman) = "de" && STR(?nameGerman) != "") } BIND (COALESCE(?namePreferred, ?nameEnglish, ?nameGerman) AS ?name) } } GROUP BY ?group ?name ORDER BY DESC(?members)
{{ template "sparqlAsyncTable" (dict "queryId" "politicsGroups" "title" "Parliamentary groups (Fraktionen)" "icon" "users" "iconVar" "group") }}

Names of groups, parties and vote proposals are published in all four national languages plus Romansh, so the tables on this page follow your browser's language preference and fall back to English, then German, where a translation is missing. People's names carry no language tag and are shown as recorded.

Interest ties and lobbying

Members of parliament must declare their outside mandates, and the declarations are published here as links between a person and a lobby organization. The useful detail is that each tie is flagged paid or unpaid, which makes the register searchable in a way the printed version never was.

SELECT ?person (SAMPLE(?n) AS ?name) (COUNT(DISTINCT ?org) AS ?paidMandates) WHERE { GRAPH <https://lindas.admin.ch/fch/curia> { ?role schema:memberOf ?org ; schema:member ?person ; schema:hasSalary true . ?org a schema:LobbyOrganization . ?person schema:name ?n . } } GROUP BY ?person ORDER BY DESC(?paidMandates) LIMIT 40

Government and administration

Three further registers describe the executive side. The Federal Council graph covers the seven-member government since 1848 — councillors, chancellors, which department each held, who was president in which year, and a curiosity found in few national datasets: the people who were elected and declined. The Staatskalender is the government directory, listing offices with their postal addresses and staff. Extra-parliamentary commissions covers the expert bodies that advise the administration from outside it.

SELECT ?year ?president ?vicePresident WHERE { GRAPH <https://lindas.admin.ch/fch/federal-council> { <https://politics.ld.admin.ch/fc/cube-president> cube:observationSet/cube:observation ?obs . ?obs schema:temporalCoverage ?year ; <https://politics.ld.admin.ch/fc/vocabulary/president> ?presidentIri . ?presidentIri schema:name ?president . OPTIONAL { ?obs <https://politics.ld.admin.ch/fc/vocabulary/vicePresident> ?viceIri . ?viceIri schema:name ?vicePresident . } } } ORDER BY DESC(?year)

Parliamentary business

One graph in this theme is modelled quite differently from the rest. Procedural requests — motions, postulates and interpellations through which members of parliament formally ask the government to act — use the PAF ontology, an activity-and-entity model borrowed from provenance vocabularies rather than the cube or schema.org shapes used everywhere else. Each request is an entity; each step in its handling is an activity with its own status text from the administration.

SELECT ?request ?information WHERE { GRAPH <https://lindas.admin.ch/fch/procedural-request> { ?request a <https://ch.paf.link/ProceduralRequestInformationEntity> ; <https://ch.paf.link/proceduralRequestInformation> ?information . } } LIMIT 500
